Repo & Deploy

纯静态站点：没有构建步骤、没有依赖、没有跟踪脚本。克隆下来双击任意 HTML 即可查看。

# 本地预览
git clone https://github.com/ucoingroup/eacoagent.git
cd eacoagent
python -m http.server 8000   # 打开 http://localhost:8000

# 部署：GitHub → Settings → Pages → Source: Deploy from a branch
# Branch: main / root → 保存，约 1 分钟后上线

零依赖

仅 HTML + CSS + 少量原生 JS，无 CDN、无框架、无字体外链，全球加载同样稳定。

可离线

三个页面均为自包含文件，可直接归档、邮件发送或刻录为资料包。

可扩展

新增页面只需复制模板并在导航与 sitemap.xml 中登记，视觉自动统一。
