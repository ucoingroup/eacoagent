使用教程与原理说明

Solana Vanity Address Generator · 单文件离线版

1. 它做了什么

不断随机产生符合 Ed25519 标准的密钥对，把 32 字节公钥做 Base58 编码得到 Solana 地址，检查它的开头 / 结尾是否命中你设定的字符串，命中即把这组密钥交给你。

2. 三步使用

填写前缀和 / 或后缀（只能用 Base58 字符），设置线程数并按需勾选开关，点击「生成」。运行期间参数会临时锁定，修改前请先点「停止」。连续模式最多保留 40 组并自动停止；导出只含公开地址（TXT，不含私钥），清空只清屏。

3. 字符规则（重要）

123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz

Base58 字母表不含容易混淆的 0（零）、O（大写 o）、I（大写 i）、l（小写 L）。输入这些字符会被拒绝，页面会给出提示。

4. 关于「首字符」的特殊限制

Solana 地址长度通常是 44 位（约 95%）或 43 位（约 5%）。44 位地址的首字符只能落在 2–9 / A–H / J 范围；只有 43 位地址才可能以 K 之后的大写字母或小写字母开头。因此小写 eaco 这类前缀在严格匹配下极罕见，勾选「忽略大小写」后可匹配 Eaco…，难度会下降好几个数量级。

5. 难度与预估时间

严格模式下每多一个字符，难度约乘以 58；忽略大小写时字母位约乘以 29。耗时是统计期望值，实际具有随机性。累计命中概率按 1 − e^(−N/难度) 计算。建议先用 3–4 个字符试跑；超过 6 个字符可能需要数天甚至更久。

6. 私钥格式与导入

地址是公钥的 Base58（43–44 字符），可公开。私钥（Base58）为 64 字节 = 32 字节 seed + 32 字节公钥，Phantom / Solflare 的「导入私钥」通常接受该格式。Keypair JSON 是 64 个 0–255 的整数数组，为 Solana CLI 标准格式。本工具直接生成 keypair，不产生助记词（12/24 词）。

8. 技术实现

单 HTML 文件、零依赖、零网络请求。优先调用浏览器原生 Web Crypto 的 Ed25519；不支持时回退内置纯 JavaScript 实现。默认多 Web Worker 并行；若 file:// 下 Worker 被拦截，自动降级为兼容模式（主线程分片运算）。每组命中结果都会用独立实现从 seed 重新推导公钥做交叉校验，确保私钥与地址确实配对。
