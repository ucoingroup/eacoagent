# 政策监控

针对关注城市清单（默认：新加坡、吉隆坡、曼谷、迪拜、清迈、中国香港）：
1. 核对三类信息：签证政策 / 加密监管 / 税务申报
2. 每条给出：最近变化、生效时间、官方来源链接、对三类人群的影响
   （游客 / 长住 / 经营者）
3. 输出「需要更新页面」清单：城市指南的哪些评分/点评要改

原则：只采用官方或主流媒体来源；转述不确定性（「拟」「传闻」要标注）。
输出后建议 issue 标题，便于在 GitHub 上跟踪。
