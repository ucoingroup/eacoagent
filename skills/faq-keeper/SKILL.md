# FAQ 维护

1. 输入：本周对话/评论中的新问题
2. 归类：已有答案 → 引用并标记重复次数；新问题 → 起草答案
3. 答案格式：一句直接回答 + 最多三条补充 + 跳转链接
4. 更新 faq.json（question, answer, links, updated, count）
5. 删除连续 90 天零命中的条目，归档不删除

输出：新增 N 条 / 更新 M 条 / 归档 K 条 + diff。
红线：涉及合规、税务、医疗的答案必须带「请咨询专业人士」。
