# 五段式成稿

输入：选题 + 目标读者 + 期望长度（默认 1200 字）。

结构：
1. 钩子：一个具体场景或反差事实，3 句内让读者决定继续读
2. 冲突：为什么这个问题难解，常见做法错在哪
3. 方法：2–4 个步骤，每步给「怎么做 + 怎么判断做对了」
4. 证据：案例或数据（没有可靠来源就明说「个人经验」）
5. 行动：今天就能做的一件事

约束：不用「首先/其次/总之」套话；每段 ≤ 5 行；专有名词首次出现给英文。
输出后追加 3 个备选标题。
