# 合规红线扫描

逐条检查以下红线，命中即标记 [STOP]：
1. 收益承诺：「保本」「稳赚」「年化 X%」
2. 资金池：代客理财、集中收款再分配、拉人头返佣
3. 虚构资质：不存在的牌照、授权、合作方
4. 数据造假：无来源的精确数字、编造案例
5. 医疗/法律/税务断言：绝对化结论
6. 隐私：收集或展示他人身份信息

输出：风险清单（原文引用 → 风险类型 → 修改建议）。
原则：宁可保守。不确定的一律建议删除或加「不构成建议」。
