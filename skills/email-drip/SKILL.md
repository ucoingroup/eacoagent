# 邮件序列

默认 5 封，节奏：D0 / D2 / D5 / D9 / D14。
- D0 交付承诺：确认对方要的东西 + 何时送达
- D2 超额交付：附一个没用过的小技巧/模板
- D5 案例：一个和你相似的人的结果（真实才可写）
- D9 邀请：一次低门槛互动（回复一个问题即可）
- D14 体面收尾：不再打扰 + 留一扇门

写作规则：标题 ≤ 12 字；每封只求一个动作；不发「just follow up」式空邮件。
合规：每封含退订方式；不发未订阅的冷群发。
